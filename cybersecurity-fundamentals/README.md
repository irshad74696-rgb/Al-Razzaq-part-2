# Cybersecurity Fundamentals

Core hands-on skills for security work: driving a shell on Linux and Windows-style tooling, and automating routine checks with Python. Each folder holds its own README with what I did, the commands, what broke and how I fixed it, plus the scripts I wrote.

| Folder | What it covers | Scripts |
| --- | --- | --- |
| [`linux-command-line-basics/`](linux-command-line-basics/README.md) | Navigating the filesystem, managing files, `chmod`/`chown` and how directory permissions behave | 3 Bash scripts |
| [`powershell-fundamentals/`](powershell-fundamentals/README.md) | PowerShell 7 on Linux: finding cmdlets, `*-Item` file management, variables, conditions and loops, with a cmdlet-to-Linux comparison | 4 PowerShell scripts |
| [`python-automation/`](python-automation/README.md) | File handling, error handling, log writing, a dry-run-first folder cleanup, a simulated network monitor and a password checker | 5 Python scripts + sample CSV |

Write-ups for each day are in the [Lab Log](../LAB-LOG.md).
